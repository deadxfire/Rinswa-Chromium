## Rinswa Browser v1.0.7 (Chromium Edition)

**Rinswa Browser** is a fast, privacy-focused, and stunning modern web browser built on the real Chromium C++ engine with Cyber-Glass UI, website frame padding, and built-in ad blocking.

### ✨ What's New in v1.0.7

- 🖼️ **Padded Website View Area with Rounded Corners**:
  - Web contents are now framed with clean 8px padding along the left, right, and bottom borders while resting flush with the URL bar / toolbar separator.
  - Native rounded squircle corners (10px top, 12px bottom) clip the web contents window seamlessly.
  - Fullscreen mode (`F11`) automatically collapses padding and corners to 0 for immersive media playback.

- 🎨 **Dynamic Theme Color Fill**:
  - The padding background area is automatically filled with the user's selected customized theme color chosen in Customize Rinswa, harmonizing with the URL bar and tab strip.

- 🔍 **New Tab Page Search Autofocus**:
  - Search input automatically focuses on tab launch, window focus, or clicking into the page, allowing instant typing without extra clicks.

- 💎 **Upgraded New Tab Page Aesthetic**:
  - Redesigned search card with frosted glassmorphism backdrop blur, glowing ambient aura, pill-shaped shortcuts toggle, and gradient action buttons.

- 🏷️ **Complete Rinswa Profile Rebranding**:
  - Profile menu and settings updated with unified Rinswa branding ("Add Rinswa profile", "Manage Rinswa profiles", "Rinswa services settings").

### 📦 Installation Options

- **`Rinswa-Browser-Setup-x64-v1.0.7.exe`** (Recommended): Full standalone offline installer with Windows 10/11 system integration, start menu and desktop shortcuts, default browser capabilities, and clean uninstaller.
- **`Rinswa.Setup.v1.0.7.exe`**: Chromium native standalone mini-installer setup.
