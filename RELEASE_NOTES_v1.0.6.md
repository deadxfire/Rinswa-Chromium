## Rinswa Browser v1.0.6 (Chromium Edition)

**Rinswa Browser** is a fast, privacy-focused, and stunning modern web browser built on the real Chromium C++ engine with Cyber-Glass UI and built-in ad blocking.

### ✨ What's New in v1.0.6

- 🌊 **Living Fluid Flowing Background Animation**:
  - Implemented high-performance 60fps organic fluid dynamics with viscous node interactions and morphing color waves (`wave-1` to `wave-4` and flowing river streams `stream-1`/`stream-2`).
  - Seamlessly animated in pure GPU-accelerated canvas and CSS shaders.

- 💫 **Radiant Search Glow & Focus Radiance**:
  - Multi-layer luminous glow aura and breathing pulse backdrop behind the search bar (`.search-glow-aura`, `.search-glow-backdrop`, `.search-glow-shimmer`).
  - Dynamic focus illumination that lights up with cybernetic cyan/violet radiance upon user typing or search engagement.

- 🛡️ **Theme Integrity & Protection**:
  - Strictly preserves Rinswa's signature look and built-in Chrome customization color palettes.
  - Automatically intercepts and blocks third-party downloaded theme extensions (`.crx` / Chrome Web Store themes) from altering browser aesthetics.

- 🚀 **Rinswa AdShield & Universal Video Popout**:
  - Built-in zero-lag ad defuser and native Picture-in-Picture for all HTML5 videos.

### 📦 Installation Options

- **`Rinswa-Browser-Setup-x64-v1.0.6.exe`** (Recommended): Full standalone offline installer with Windows 10/11 system integration, start menu and desktop shortcuts, default browser capabilities, and clean uninstaller.
- **`Rinswa.Setup.v1.0.6.exe`**: Chromium native standalone mini-installer setup.
