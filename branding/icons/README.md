# Platform Icons
This directory contains application icons for different operating systems.

## Requirements
* **Windows:** Provide `default.ico` and `document.ico` (multi-resolution from 16x16 to 256x256).
* **macOS:** Provide `app.icns` and `document.icns` (resolutions up to 1024x1024).
* **Linux:** Provide `default16.png`, `default32.png`, `default48.png`, `default64.png`, `default128.png`, and a scalable `default.svg` for Freedesktop standards.
